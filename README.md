# 程優教育科技｜主管人才評比系統 — 部署包

這是一個**靜態網站**，部署後會得到一個公開網址（手機、電腦、其他 CEO 都能開）。

## 📦 內容
| 檔案 | 說明 |
|---|---|
| `index.html` | **主程式（首頁）**。電影級 3D 立體評比系統，部署後就是網站首頁。需要網路（會載入 3D 繪圖函式庫）。 |
| `備用_自包含版.html` | 無任何外部相依的備援版（純 CSS 3D）。若部署平台擋外部資源導致 `index.html` 空白，改用這個當首頁即可。 |
| `自評問卷系統_GoogleAppsScript.gs` | Google 自評問卷＋後台「一鍵建置」腳本（非網站的一部分，另在 script.google.com 使用）。 |
| `建置與使用說明.md` | 完整使用說明（三軸模型、8 型、雲端同步、公司評編輯、手機操作等）。 |

## 🚀 在 Manus 上部署（取得公開網址）

把這個 zip 上傳到 Manus，然後給它這段指令即可：

> 「請把這個壓縮檔當成**靜態網站**部署，入口頁是 `index.html`，部署後給我公開網址。」

Manus 會解壓、部署，並回傳一個像 `https://xxxx.manus.app`（或它提供的網域）的網址。
用手機開那個網址、傳給其他 CEO 都可以。

> 若部署後畫面全黑/空白（平台擋了外部函式庫），請改把 `備用_自包含版.html` 設為入口，或將它改名為 `index.html` 覆蓋。

- **Netlify Drop**：https://app.netlify.com/drop ，把資料夾拖進去即得網址（免註冊）。

## ☁ 讓全體 CEO 看「同一份資料」（選用）
1. 先用 `自評問卷系統_GoogleAppsScript.gs` 在 script.google.com 建好表單與試算表。
2. 試算表 →「檔案 → 共用 → 發布到網路 → 選『CEO評核台』＋ CSV」→ 複製網址。
3. 用記事本打開 `index.html`，找到開頭這行，貼上網址：
   ```js
   const SHEET_CSV_URL = "你的CSV網址";
   ```
4. 重新部署。之後每個人開網址都讀同一張表、看到同一個立體圖（每 60 秒自動同步，或按頂部「☁ 同步」）。
   - 也可不改檔，部署後在系統右上按「☁ 同步」貼網址（但那是存在各自瀏覽器，需每台各貼一次）。
